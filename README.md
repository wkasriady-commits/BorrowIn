4th Semester Visual Programming Project BorrowIn is an online library borrowing application developed using C# and Windows Forms, with SQL Server as the database management system. The project was developed as part of an academic software development project and aligned with UN Sustainable Development Goal 4: Quality Education.

The application is designed to simplify the process of borrowing and managing library books digitally. Users can browse available books, submit borrowing requests, track borrowing status, and manage their borrowed books. The system also provides features such as due dates, pickup codes, book requests, and return tracking.

BorrowIn includes dedicated functionalities for users, librarians, and administrators, allowing each role to manage relevant activities within the system. The project also implements database integration to manage user, book, and borrowing data efficiently.

Through this project, we applied software development and database management concepts to build a functional library information system that supports more accessible and organized access to learning resources.
